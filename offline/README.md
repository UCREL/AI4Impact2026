# Offline fallback

Every notebook's **core** cells run without internet. Use the tier that matches the situation.

| Tier | Situation | What to do |
| --- | --- | --- |
| 0 | Campus Wi-Fi works | Open notebooks in Colab from the main README |
| 1 | Internet weak | Join a workshop mobile hotspot; skip stretch cells |
| 2 | No internet, power on | Join the workshop's local Wi-Fi and open the address the facilitator gives you: a JupyterLite copy of all core notebooks and data, running Python in your browser |
| 3 | No power or devices | Use the printed lab sheets and project worksheets in your pack |

Facilitators: the JupyterLite build (`jupyterlite/`), Python installer and wheel files, and printable sheets (`sheets/`) are added here before the workshop. Test the build on the travel router by Friday 20 November.
