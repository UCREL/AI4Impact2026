## Overview

This repository holds the notebooks, data and lab sheets for **AI for Impact 2026**, a free five-day hands-on workshop for 50 university staff and students from Peter University and neighbouring institutions in Anambra State.

Across the week, six mixed teams each build a **bilingual community knowledge assistant**: a small tool that answers everyday questions from trusted local sources, in Igbo or English, and shows where each answer came from. No prior programming is required.

- Event website: https://ucrel.github.io/AI4Impact2026/
- A partnership between **Lancaster University** (UCREL, School of Computing and Communications) and **Peter University Achina-Onneh**
- Funded by the **Friends of Lancaster University in America (FLUA)**

> Materials for each day are added to this repository on the morning of that day.

## How to use the notebooks

1. Click an **Open in Colab** badge in the day's folder (you need a Google account).
2. Run each cell with **Shift + Enter**, from top to bottom.
3. Edit only the words between quotes in the cells marked ✏️ **Your turn**.
4. **Core** cells run anywhere, even offline. Cells marked ⭐ **STRETCH** need internet and are optional.
5. No internet? Ask a facilitator for the offline copy (see [`offline/`](offline/)).
