# Project template: Community Knowledge Assistant

Each group copies this folder, names its assistant (ideally in Igbo), and fills it in day by day.

| Day | Subtask | File you produce |
| --- | --- | --- |
| Mon | Gather | `knowledge_base.csv` (columns: id, question_en, question_ig, answer_en, answer_ig, topic, source, licence) |
| Tue | Understand | `router.ipynb` and its accuracy score |
| Wed | Extract | `glossary.csv` (term_en, term_ig, type) and `fact_cards.csv` |
| Thu | Answer | `assistant.ipynb` |
| Fri | Evaluate and present | `test_report.csv` and `pitch.pdf` |

Group roles (rotate daily): driver, data lead, Igbo language lead, ethics and testing lead, presenter.
